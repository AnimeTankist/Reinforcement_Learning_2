# Лабораторная работа: обучение с подкреплением

Прикладная задача: **управление запасами на складе** (из списка примеров задания).
Алгоритм: **табличный Q-learning** (epsilon-greedy, off-policy TD(0)).

Робот на клеточном поле не используется — задача и среда другие.

## Быстрый старт

```powershell
# из каталога проекта
python main.py all                  # обучение + оценка + демонстрация (по умолчанию 10 000 эпизодов)
python main.py train --episodes 20000 --alpha 0.15
python main.py evaluate             # оценить сохранённую Q-таблицу
python main.py demo                 # один эпизод обученного агента в виде таблицы
python -m unittest discover -s tests -t .   # тесты (18 штук)
```

Зависимости — только `numpy` и `matplotlib` (см. `requirements.txt`), gymnasium не нужен:
среда написана вручную и полностью прозрачна для отчёта.

## Что решается

Склад ежедневно получает заказ от агента, затем сталкивается со случайным спросом
(в выходные он выше). Агент выбирает размер заказа, чтобы максимизировать суммарную
прибыль за 30 дней: не платить лишнего за хранение, но и не терять продажи из-за дефицита.

| Элемент MDP | Значение |
|---|---|
| Состояние | `(остаток 0..20, день недели 0..6)` → 147 состояний |
| Действие | размер заказа: `0, 2, 5, 10` шт. |
| Спрос | `Poisson(mean[день])`, `mean = (3, 3, 3, 3, 4, 6, 6)` |
| Награда | `10*продано - 6*принято - 2*[заказ>0] - 0.4*остаток - 6*недостача` |
| Эпизод | 30 дней (`terminated` после 30-го шага) |

## Результаты (10 000 эпизодов, seed 0)

| Метрика (200 эпизодов оценки) | Q-learning | Случайная политика |
|---|---|---|
| Средняя награда за эпизод | **390.07 ± 44.13** | 241.09 ± 76.14 |
| Доля удовлетворённого спроса | **0.974** | 0.935 |
| Доля дней с дефицитом | **0.057** | 0.081 |
| Средний остаток на складе | 3.92 | 9.55 |
| Недостача за эпизод, шт. | 3.07 | 7.66 |

Средняя награда за 100 эпизодов выросла с 255.73 (первые 100) до 382.27 (последние 100),
обучение занимает ~7 с на CPU.
